계정 삭제 요청

앱: 집구르망 (com.jipgourmand.app)

집구르망은 사용자가 자신의 계정과 관련 데이터를 직접 삭제할 수 있는 두 가지 방법을 제공합니다.

방법 1. 앱 내에서 직접 삭제 (권장)

1. 집구르망 앱 실행 → 로그인
2. 하단 탭 마이페이지 → 우상단 설정 아이콘
3. 하단의 계정 삭제 버튼 탭
4. 안내 다이얼로그에서 삭제 확인

이 방법은 즉시 처리되며, 별도 문의 없이 모든 관련 데이터가 영구 삭제됩니다.

방법 2. 이메일로 요청

앱을 이미 삭제했거나 로그인할 수 없는 경우 다음 이메일로 요청해주세요.

  • 사용자가 작성한 모든 게시물, 댓글, 좋아요, 즐겨찾기
  • 식단 계획, 장보기 리스트, 가족 구성원 정보

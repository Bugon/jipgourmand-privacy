집구르망 개인정보 처리방침

시행일자: 2026년 5월 4일 · 최종 수정일: 2026년 7월 9일

집구르망 운영자(이하 "운영자")는 모바일 애플리케이션 집구르망(이하 "서비스")을 이용하는 사용자의 개인정보를 보호하고 관련 법령을 준수하기 위해 본 개인정보 처리방침을 두고 있습니다.

1. 수집하는 개인정보 항목

서비스 제공을 위해 다음의 정보를 수집·이용합니다.

2. 개인정보 수집 및 이용 목적

  • 회원 식별 및 인증: 소셜 로그인 기반 계정 생성·유지·관리
  • 서비스 제공: 가족 맞춤형 AI 식단 생성, 장보기 리스트 관리, 즐겨찾기 레시피 저장
  • 커뮤니티 기능: 게시물 작성·열람, 댓글, 좋아요, 팔로우, 신고/차단
  • 푸시 알림: 새 팔로워, 댓글 등 사용자 활동 관련 알림 전송 (사용자가 설정에서 끌 수 있음)
  • 광고: AdMob을 통한 광고 노출 및 측정 (수익화 및 AI 호출 어뷰징 방지)

3. 개인정보의 보유 및 이용 기간

운영자는 사용자의 회원 자격이 유지되는 동안 개인정보를 보유합니다. 사용자가 앱 내 "계정 삭제" 기능을 이용하여 탈퇴하는 경우, 다음을 즉시 영구 삭제합니다.

  • 사용자 계정 정보 (Firebase Auth)
  • 사용자 프로필 (닉네임, 사진 등)
  • 사용자가 작성한 게시물, 댓글, 즐겨찾기, 식단/장보기 데이터
  • 가족 그룹 멤버십 (마지막 멤버일 경우 가족 그룹 데이터 전체 삭제)
  • 팔로우 관계, 푸시 알림 토큰

관련 법령에 의하여 일정 기간 보존이 필요한 경우(예: 전자상거래법, 통신비밀보호법) 해당 법령에서 정한 기간 동안 분리 보관 후 파기합니다.

4. 개인정보의 제3자 제공

운영자는 사용자의 개인정보를 외부에 판매하거나 제공하지 않습니다. 단, 다음의 경우 예외로 합니다.

  • 사용자가 사전에 동의한 경우
  • 법령에 의하여 제출 의무가 있거나, 수사 목적으로 적법한 절차에 따라 요구되는 경우
  • 커뮤니티 기능 특성상 사용자가 작성한 게시물·댓글·프로필은 다른 이용자에게 공개됨

서비스 운영을 위해 다음 외부 서비스에 일부 개인정보 처리를 위탁합니다.

6. AI 기능 이용 안내

본 서비스는 가족 맞춤 식단·레시피를 생성하기 위해 아래 정보를 Google LLC의 Gemini API로 전송합니다.

  • 가족 구성원의 이름, 성별, 나이, 국적, 소개, 알레르기, 비선호 음식
  • 사용자가 식단 생성 시 직접 입력한 요청사항

전송은 사용자가 앱에서 명시적으로 동의한 경우에만 이루어집니다. 최초 AI 기능 이용 시 전송 항목을 안내하고 동의를 받으며, 동의하지 않으면 AI 기능은 이용할 수 없습니다. 동의는 앱 내 "설정 → AI 데이터 제공 동의"에서 언제든지 철회할 수 있고, 철회 후 다시 AI 기능을 이용하면 동의를 재요청합니다.

전송된 정보는 식단·레시피 생성에만 이용되며 광고 목적으로 이용되지 않습니다. Google은 자체 정책에 따라 데이터를 처리합니다.

7. 광고 식별자 및 광고

본 서비스는 AdMob(Google) 광고를 표시합니다.

  • Android: 광고 식별자(AAID)가 광고 노출·측정에 활용될 수 있습니다. 기기 설정 → Google → 광고에서 광고 ID 재설정 또는 맞춤 광고 거부가 가능합니다.
  • iOS: 본 서비스는 App Tracking Transparency 권한을 요청하지 않으며 광고 식별자(IDFA)를 수집하지 않습니다. 따라서 다른 회사의 앱·웹사이트에서의 활동과 연결한 추적을 하지 않으며, 비개인화 광고만 표시됩니다.

8. 사용자의 권리 및 행사 방법

  • 열람·수정: 앱 내 "마이페이지", "프로필 편집", "가족 설정" 메뉴에서 직접 수정
  • 삭제 (탈퇴): 앱 내 "설정 → 계정 삭제"에서 계정 및 모든 관련 데이터 영구 삭제. 별도 문의 없이 사용자가 직접 실행 가능
  • 알림 수신 거부: 앱 내 "설정 → 알림 설정"에서 알림 종류별 on/off
  • 다른 사용자 차단: 사용자 프로필에서 차단 가능, 차단 목록은 "설정 → 차단 목록"에서 관리
  • 문의: 본 처리방침 하단의 연락처로 문의

9. 개인정보의 안전성 확보 조치

  • 전송 구간 암호화 (HTTPS/TLS)
  • Firebase 보안 규칙(Firestore Security Rules)에 따른 데이터 접근 제어
  • 관리자 권한 최소화 및 접근 통제
  • Cloud Functions Admin SDK를 통한 안전한 백엔드 처리

10. 만 14세 미만 아동의 개인정보

본 서비스는 만 14세 미만 아동의 개인정보를 의도적으로 수집하지 않습니다. 만약 보호자 동의 없이 만 14세 미만 아동의 개인정보가 수집된 사실이 확인되면 즉시 삭제 처리합니다.
